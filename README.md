# UDMS — Зэвсэгт Хүчний Дүрэмт Хувцасны Удирдлагын Систем

**Uniform Distribution & Management System — Mongolian Armed Forces (Army-only build)**

Гурван шаттай удирдлагын шатлал дээр суурилсан дүрэмт хувцасны хангамж, агуулах, хуваарилалтын систем: **ЗХЖШ → Командлал (6) → Анги (43)**.

---

## 1. Байгууллагын бүтэц

```
                              ЗХЖШ (Жанжин штаб)
                                     │
      ┌───────────┬───────────┬─────┴─────┬───────────┬───────────┐
  Хуурай замын  Тусгай хүчний Агаарын   Барилга,   Кибер аюулгүй  Жанжин штабын
  цэргийн         командлал   цэргийн  инженерийн   байдлын       шууд харьяа
  командлал                  командлал цэргийн      командлал     командлал
                                        удирдах
                                        газар
   (12 анги)      (6 анги)    (5 анги)  (5 анги)     (1 анги)      (14 анги)
```

Нийт **43 анги**, **6 Командлал**, **1 ЗХЖШ** — бүгд өөрийн гэсэн crest/лого, нэвтрэх эрхтэй.

Нүүр хуудсан дээр ЗХЖШ-ийн лого дээрээс тус бүрийн Командлал руу урсгалын анимацитай холбоос гаргаж, Командлал дээр дарахад харьяа анги логонууд нь дугаарлагдаж нээгдэнэ.

---

## 2. Нэвтрэх систем

Нүүр хуудсан дээрх аль ч лого (ЗХЖШ / Командлал / Анги) дээр дарахад нэвтрэх хуудас руу шилждэг. Бүх демо дансны **нууц үг: `12345`**.

| Түвшин | Хэрэглэгчийн нэр | Тоо |
|---|---|---|
| ЗХЖШ | `ЗХЖШ` | 1 |
| Командлал | `ХЗЦК`, `ТХК`, `АЦК`, `БИЦУГ`, `КАБК`, `ЖШК` | 6 |
| Анги | Ангийн дугаар (жишээ нь `014`, `084`, `330`, `301`...) | 43 |

Нэвтрэх хуудсан дээрх "Демо данснууд" жагсаалтаас дарахад автоматаар бөглөж, шууд нэвтэрнэ.

Амжилттай нэвтэрсний дараа **4 ангиллын карт** (Офицер / Ахлагч / Хугацаат цэрэг / Гэрээт цэрэг) харагдана — эдгээр нь тухайн байгууллагын агуулахын **нөөцийг ангилалаар** харуулна (Ерөнхийлөгчийн 141 зарлигийн бүлгүүдэд үндэслэсэн: 1-р бүлэг → Офицер, 2-р бүлэг → Офицер/Ахлагч/Гэрээт, 3-р бүлэг → Хугацаат цэрэг). Карт дээр дарахад Агуулах таб уг ангиллаар шүүгдэж нээгдэнэ.

## 3. Цэс (Таб)-ын бүтэц — түвшин бүрт өөр

### ЗХЖШ / Командлал (4 таб)
| Таб | Юу хийдэг |
|---|---|
| **Шинээр бүртгэх** | ЗХЖШ: төв каталогт шинэ нөөц оруулах (загвар нэмэх, bulk-import template). Командлал: өөрийн агуулахад шууд нөөц бүртгэх (орон нутгаас авсан г.м). |
| **Агуулах** | Одоогийн үлдэгдэл (4 ангиллаар шүүгдэнэ), ирсэн ачааг хүлээн авах, доод шатанд (Командлал/Анги) илгээх. |
| **Хуваарилалт** | Харьяа Командлал/Анги тус бүрт хэдэн ширхэг, ямар загвар илгээснийг харах. |
| **Хангамжийн хүсэлт** | Доод шатнаас ирсэн хүсэлтийг хүлээж авах/татгалзах, эсвэл дээд шатанд хүсэлт илгээх. |

### Анги (5 таб)
Дээрх 4 + **Алба хаагчийн профайл**:
- Алба хаагчийн мэдээлэл, биеийн хэмжээс
- Бүх түүхэн олголт (5+ жилийн)
- **Дараагийн ээлжит олголт** (юу, хэзээ) — автоматаар тооцдог
- **Биет байдлаар / Мөнгөн урамшуулал** — олголтыг биет эд зүйл эсвэл мөнгөн хэлбэрээр авсан эсэхийг ялгаж бүртгэдэг (мөнгөн урамшуулал сонговол агуулахын үлдэгдлээс хасахгүй)
- Размер солилцооны (Exchange) түүх

## 4. Технологи

- **React 18 + TypeScript**, Vite 6
- **Tailwind CSS v4** (CSS-based `@theme`, өнгөний токенууд: `teal-*` = суурь фон (Prompt Blue #0B132B), `foam-*` = өнгө тэмдэглэгээ (AI Green #39FF88))
- **Poppins** фонт
- Бүх дата **localStorage**-д хадгалагдана (сервэргүй, демо зориулалттай)

```bash
npm install
npm run dev      # хөгжүүлэлтийн горим
npm run build    # production build
```

## 5. Дата загварын товч тойм

- `Command` — 6 Командлал, `Department` (Анги) бүр `commandId`-аар харьяалагддаг
- `UniformItem` — каталогийн загвар бүр (`sizeStock`, `totalStock`)
- `StockHolding` — Командлал/Анги-ийн өөрийн агуулахын үлдэгдэл (ЗХЖШ-ийн үлдэгдэл `UniformItem.sizeStock`-д шууд хадгалагдана)
- `SupplyTransfer` — ЗХЖШ→Командлал, Командлал→Анги чиглэлийн бодит шилжүүлэг (илгээсэн/хүлээн авсан төлөвтэй)
- `SupplyRequest` — доод шатнаас дээш чиглэлийн хүсэлт (хүлээгдэж буй/биелсэн/татгалзсан)
- `Personnel` — цэргийн алба хаагч, `rankCategory` + `serviceType` (Conscript/Contract)
- `DistributionRecord` — алба хаагчид олгосон бүртгэл, `receivedPhysically` талбартай (биет/мөнгөн)
- `ExchangeRecord` — размер солилцооны бүртгэл
